تفعيل إظهار جميع الأجهزة تلقائياً

حالياً، قواعد الفايربيس تسمح فقط بقراءة الجهاز إذا كنت تعرف الماك بتاعه، لكنها تمنع طلب قائمة بجميع الأجهزة دفعة واحدة.

الحل في 3 خطوات بسيطة:
  1. افتح صفحة قواعد الفايربيس: اضغط هنا لفتح قواعد الفايربيس
  2. استبدل القواعد بالكود أدناه ثم اضغط Publish.
  3. قم بعمل ريفريش لصفحة الأدمن وستظهر كل الأجهزة المسجلة تلقائياً!
{
  "rules": {
    ".read": false,
    ".write": false,
    "devices": {
      ".read": "auth != null",
      ".write": "auth != null",
      "$deviceId": {
        "commandQueue": { ".indexOn": ["timestamp"] },
        "trips": { ".indexOn": ["startTime", "endTime"] },
        "temp_trip": { ".indexOn": ["timestamp", "receivedAt"] }
      }
    }
  }
}
