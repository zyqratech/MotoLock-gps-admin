تأكيد حذف الجهاز نهائياً

تحذير هام: هذه العملية لا يمكن التراجع عنها. سيتم حذف عقدة الجهاز بالكامل من قاعدة بيانات الفايربيس (Firebase) وإلغاء تتبعه ومسح مواقعه وأوامره من النظام.
--
--
استخدم هذا الخيار في حال تلف أو احتراق شريحة ESP واستبدالها لعميل، لإزالة المعرف القديم لتفريغ اللوحة واستقبال الجهاز الجديد.

تفعيل إظهار جميع الأجهزة تلقائياً

حالياً، قواعد الفايربيس تسمح فقط بقراءة الجهاز إذا كنت تعرف الماك بتاعه، لكنها تمنع طلب قائمة بجميع الأجهزة دفعة واحدة.

الحل في 3 خطوات بسيطة:
  1. افتح صفحة قواعد الفايربيس: اضغط هنا لفتح قواعد الفايربيس
  2. استبدل القواعد بالكود أدناه ثم اضغط Publish.
  3. قم بعمل ريفريش لصفحة الأدمن وستظهر كل الأجهزة المسجلة تلقائياً!
{
  "rules": {
    ".read": false,
    ".write": false,
    "devices": {
      ".read": "auth != null",
      "$deviceId": {
        ".read": "auth != null",
        ".write": "auth != null && $deviceId.matches(/^[0-9A-Fa-f]{12}$/)",
        "commandQueue": { ".indexOn": ["timestamp"] },
        "trips": { ".indexOn": ["startTime", "endTime"] },
        "temp_trip": { ".indexOn": ["timestamp", "receivedAt"] }
      }
    }
  }
}

إعدادات الاتصال والفايربيس

حل بطء Firebase Console: هذه الصفحة صُممت للاستماع المباشر لحالة الأجهزة دون تحميل آلاف نقاط الرحلات دفعة واحدة، مما يمنحك سرعة فائقة ولا يستهلك ذاكرة المتصفح.
تنظيف العقد والأجهزة الوهمية:

حذف العقد غير الصالحة مثل (command, commandQueue والأحرف العشوائية) مع الحفاظ التام على أجهزتك الحقيقية (12 خانة Hex).

تفريغ مسارات temp_trip لتوفير الباقة:

حذف نقاط الرحلات المتراكمة في الفايربيس وتوفير باقة التنزيل (Download Bandwidth) فوراً بدون التأثير على حالة الأجهزة.
