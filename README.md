# 🏍️ دليل استخدام ونشر لوحة تحكم MotoLock Admin Dashboard

لوحة تحكم خفيفة وفائقة السرعة لمراقبة جميع دراجات وأجهزة **MotoLock GPS** لحظياً على خريطة حية، وحساب إحصائيات الأجهزة المتصلة والمتحركة وتسميتها بسهولة، وتجنب مشاكل ثقل وتجميد Firebase Console.

---

## 🚀 التشغيل المباشر السريع (Local)

يمكنك فتح اللوحة فوراً على جهازك بأي من الطرق التالية:
1. **بالنقر المزدوج:** افتح ملف `admin/index.html` في متصفح Google Chrome أو Edge أو Firefox.
2. **باستخدام Live Server / خادم محلي:**
   ```bash
   cd admin
   npx serve .
   ```
   أو افتح الملف مباشرة من المسار: `file:///z:/MotoLock app/admin/index.html`.

---

## 🌐 خطوات الرفع على GitHub Pages لمتابعة الأجهزة من الهاتف

لتتمكن من فتح اللوحة من هاتفك أو أي متصفح في العالم برابط مباشر ومجاني:

### الطريقة 1: إنشاء مستودع (Repository) مخصص للوحة التحكم (موصى بها)
1. على موقع [GitHub](https://github.com)، أنشئ مستودعاً جديداً (مثال: `motolock-admin`).
2. قم برفع ملف `index.html` الموجود داخل مجلد `admin` إلى المستودع.
3. ادخل إلى إعدادات المستودع **Settings** -> ثم قسم **Pages** (من القائمة الجانبية).
4. تحت **Build and deployment**:
   - اختر **Source**: `Deploy from a branch`.
   - اختر الفرع `main` والمجلد `/ (root)`.
   - اضغط **Save**.
5. خلال ثوانٍ سيظهر لك رابط موقعك المباشر، مثل:
   `https://<your-username>.github.io/motolock-admin/`
6. احفظ الرابط على شاشة هاتفك الرئيسية (Add to Home Screen) ليعمل كتطبيق جوال أنيق وسريع.

## 🔒 إعداد قواعد أمان Firebase (Realtime Database Rules)

لكي تتمكن لوحة التحكم من اكتشاف وقراءة جميع الأجهزة المسجلة تلقائياً، تأكد من أن قواعد قاعدة البيانات في Firebase Console تتيح القراءة لمسار `/devices`:

1. ادخل إلى **Firebase Console** -> مشروع `motolock-gps`.
2. من القائمة الجانبية، اختر **Realtime Database** -> ثم تبويب **Rules**.
3. تأكد من أن القواعد مطابقة للشكل التالي:

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "devices": {
      ".read": "auth != null",
      ".write": "auth != null",
      "$deviceId": {
        "commandQueue": {
          ".indexOn": ["timestamp"]
        },
        "trips": {
          ".indexOn": ["startTime", "endTime"]
        },
        "temp_trip": {
          ".indexOn": ["timestamp", "receivedAt"]
        }
      }
    }
  }
}
```
4. اضغط **Publish**.

> [!TIP]
> **في حالة عدم تعديل القواعد:**
> توفر اللوحة زر **"+"** في الشريط العلوي لإدخال معرف الماك للجهاز (مثل `6CC84044E15A`) ومتابعته فورياً بشكل منفرد حتى لو كانت القواعد تمنع قراءة جذر الدليل `/devices`.

## 🌟 أبرز ميزات اللوحة

1. **إحصائيات فورية (KPIs):** إجمالي الأجهزة، المتصلة حالياً، المتحركة، المتوقفة، وتوفير الطاقة.
2. **خريطة تفاعلية حية (Leaflet):**
   - علامة خضراء نابضة 🟢: دراجة متصلة وتتحرك حالياً (تعرض السرعة لحظة بلحظة).
   - علامة زرقاء 🔵: دراجة متصلة ومتوقفة.
   - علامة حمراء 🔴: دراجة غير متصلة منذ أكثر من دقيقتين.
   - إمكانية التبديل بين الخريطة الداكنة وخريطة الأقمار الصناعية (Satellite) وخريطة الشوارع.
   - زر توجيه مباشر لإحداثيات الدراجة على Google Maps.
3. **تسمية الأجهزة (Custom Naming):**
   - اضغط على أيقونة القلم ✏️ بجوار اسم أي دراجة لتغيير اسمها (مثال: "دراجة محمد - بوكسر 150").
   - يتم حفظ الاسم محلياً ومزامنته سحابياً على Firebase ليظهر الاسم لجميع المستخدمين.
4. **متجاوبة تماماً مع الهاتف (Mobile Ready):**
   - شريط تنقل سفلي للتبديل السريع بين الخريطة وقائمة الأجهزة على شاشات الموبايل الصغيرة.
